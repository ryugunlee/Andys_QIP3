## 2. 채점 앵커 — 0~100점의 기준

항목마다 **S(90 이상) · B(65) · F(35 미만)** 앵커를 둔다. A·C·D는 앵커 사이에서 정한다.
Q1·Q6·Q8·Q9는 raw 수치가 있으면 **코드가 앵커 사이를 선형 보간해 점수를 재계산**한다(채점자 점수를
덮어쓴다). Q2~Q5·Q7은 채점자(LLM 또는 사람)가 앵커에 맞춰 직접 매기되 근거 서술이 필수다.

| 코드 | S (90 이상) | B (65) | F (35 미만) |
|---|---|---|---|
| Q1 | 확정 매출(수주잔고+1년 내 확정 반복매출) ÷ 연매출 **1.0배 이상**, 구속력 있는 계약 | 0.5배 안팎 | 0.2배 미만, 또는 MOU·구두 수준뿐(구속력 없음 → 상한 34) |
| Q2 | 점유율 1~2위이고 3년 상승, 인지도가 원문·통계로 확인 | 중위권 유지 | 하위권이거나 3년 하락 |
| Q3 | 대체 난이도 높음 — 특허·인증·공정 세분화로 경쟁사가 단기 복제 불가 | 차별성 있으나 대체 가능 | 범용 제품·가격 경쟁 |
| Q4 | 수요 성장 + 규제 우호·중립 + 10년 존속 의심 없음 (산업 PER이 시장 평균 이하면 근거에 기재) | 수요 정체, 규제 불확실 | 수요 축소, 규제 역풍, 또는 소멸 경로 확인 |
| Q5 | 다른 산업의 확정 수요와 계약·양산 단계로 연결, 또는 신사업이 ④⑤단계 | ②③단계 | ①단계뿐이거나 없음 |
| Q6 | 사외이사 과반 + 특수관계자 거래(**연결 종속회사 제외**) 매출 5% 미만 + 결격 없음 | 과반 미달, 또는 5~15% | 15% 이상 또는 3년 증가 추세. **결격 해당 시 F 고정** |
| Q7 | 소각 이력 + 배당이 영업CF 내 + 영업권 손상 0회 | 소각 없는 매입, 손상 1회 | 차입 배당, 또는 손상 2회 이상 |
| Q8 | 최대 고객 10% 미만 **그리고** 최대 세그먼트 영업이익 60% 미만 | 고객 20% / 세그먼트 80% | 고객 30% 이상 **또는** 세그먼트 90% 이상 |
| Q9 | 단일 국가 매출·생산 30% 미만이고 환위험 헤지 | 30~50% | 50% 이상이고 미헤지(미헤지면 상한 65) |

- 증거가 언론·리포트뿐(3급 이하)이거나 인용 대조에 실패하면 `weak` → **점수 상한 65**.
- 근거 서술(rationale)이 비어 있으면 그 항목은 `missing`으로 취급한다(원칙 ①).

## 3. 등급·종합·배수

- **등급 밴드**(항목·종합 공통): S ≥ 90 / A ≥ 80 / B ≥ 65 / C ≥ 50 / D ≥ 35 / F < 35.
- **종합점수** = Σ(항목 점수 × 가중) ÷ Σ(유효 항목 가중). 유효 항목(observed·weak)이 **6개 미만이면 판정 미완료**.
- **결격**(Q6, 종합과 무관하게 F·기각): 핵심 사업 물적분할 후 중복상장 / 최근 5년 지배주주·경영진 배임·횡령·분식
  확정 판결 또는 기소 진행 / 소액주주에 불리한 합병·분할 비율 강행.
- **배수**: S 1.25 / A 1.10 / B 1.00 / C 0.75 / D 0.50 / F 0. **Q6이 C 이하면 상한 1.0**(가점 불가).
- **판정**: 배수 ≥ 1.0 채택 / 0.75 제한 채택 / 0.5 보류(리스트 유지, 신규 매수 없음) / 0 기각.
- 배수는 모멘텀 집행률과 **곱하지 않는다** — 상세 페이지에 나란히 놓는다(이 프로그램은 절대 비중을 내지 않는다).
- **유효기간 6개월.** 만료 판정은 표현 계층이 `valid_until`로 처리한다.
- **주의 항목** = 등급 C 이하 항목. 등급카드에 사유 한 줄과 함께 나열해 다음 확인 대상으로 삼는다.

## 4. ★ 플래그 — 설명되지 않는 주가 추세

점수가 아니라 **확인 신호**다. 코드가 DB에서 계산한다(뉴스를 쓰지 않는다 — 주가 서술은 근거 금지).
- 6개월 수익률 |r| ≥ **30%** 인데, 최근 연간 영업이익 변화율이 **같은 방향이 아니거나 ±10% 이내**(변화 없음)
  → `UNEXPLAINED_UP` / `UNEXPLAINED_DOWN`. 직전 영업이익이 0 이하이거나 데이터가 없으면 계산하지 않는다.
- 등급카드 맨 아래에 수익률·영업이익 변화율과 함께 표시한다. 사람이 원인(공시·산업 변화)을 찾는다 —
  이유 없는 하락은 기회일 수도, 미공개 악재일 수도 있다. 이유 없는 상승은 Q4·Q5 근거가 실체인지 되묻는다.

## 5. 관측값 JSON — 채점자(LLM·사람)의 산출물

```json
{ "ticker": "005930", "asof": "2026-03-18", "sector_group": "일반", "source_title": "사업보고서 2025",
  "observations": [
    { "item": "Q1", "status": "observed", "score": 78,
      "rationale": "수주잔고 12.3조는 연매출 15.1조의 0.81배. 주요계약 3건은 구속력 있는 장기 공급계약.",
      "raw": { "committed_to_revenue": 0.81, "binding_contracts": true },
      "evidence": [ { "source": "사업보고서 2025 · II-4 수주상황", "date": "2026-03-18", "grade": 1,
                      "quote": "수주잔고 합계 12,300,000", "locator": "II. 사업의 내용 4. 수주상황" } ],
      "note": "" },
    { "item": "Q3", "status": "missing", "score": null, "rationale": "", "raw": null, "evidence": [], "note": "특허·인증 서술 없음" }
  ] }
```

- `status`: observed / weak(증거 약함·인용 대조 실패) / missing(원문에 없음) / not_investigated(아직 안 봄).
- `grade`(증거 등급): 1 공시 원문·주석·계약 / 2 산업 통계·거래상대방 발언 / 3 리포트·언론.
- raw 필드 목록은 `collection/qualitative/items.py`가 단일 소스다. 파일은 `qualitative/observations/<티커>.json`(git 추적).

## 6. 절차

1. 원문: `extract`에 파일을 주지 않으면 한국은 OpenDART 사업보고서(`DART_API_KEY`), 미국은 EDGAR 10-K
   (`EDGAR_USER_AGENT`)를 자동으로 받아 `qualitative/sources/`에 저장한다. 사업보고서는 기본으로 대제목
   I·II·VI·VII·X·XI만 넣는다(약 12만 토큰. III 재무·주석은 `--sections`로). 파일 직접 투입(txt/md/html/pdf)도 그대로 된다.
2. `python grade_qualitative.py extract <티커> [원문] [--tier quick|deep] [--provider anthropic|compat] [--items Q1Q4]`
   — LLM **1회 호출**로 9항목을 채점한다. **quick**(기본)은 Sonnet 5 effort low 또는 OpenAI 호환 저가 모델
   (DeepSeek 등, `COMPAT_LLM_*` 환경변수)에 섹션 II·VI·X만(삼성전자 8만 토큰 ≈ $0.25), **deep**은 Opus 5에
   III(재무·주석)까지(33만 토큰 ≈ $2). 코드가 응답을 스키마 검증·인용 대조·어휘 검사한다. 원문 60만 자 초과는 `--force`.
3. 사람 검토: 관측값 JSON의 점수·근거를 고친다. 사람이 직접 채우는 경우 `template` 명령으로 빈 파일을 만든다.
4. `python grade_qualitative.py grade <티커> [--market] [--no-save]` — 수치 재계산·종합·배수·★ 플래그 → 등급카드
   출력, `qualitative_grades` 저장.

LLM 사용 규칙: 앵커에 맞춰서만 채점하고 근거를 쓴다 / 원문에 없으면 `missing`이 정답 / 인용은 원문 그대로
복사(코드가 대조) / 주가·수급 정보는 어떤 필드에도 넣지 않는다 / 프롬프트에 정량 점수·주가를 넣지 않는다.

## 7. 등급카드

```
[식별]   005930 / 섹터군 일반 / 관측 2026-03-18 / 판정 2026-09-15 / 유효 2027-03-01
[항목]   Q1 확정이익 A(80)  Q2 시장지위 S(92)  Q3 기술 B(70)  Q4 산업전망 B(65)  Q5 잠재력 C(55)
         Q6 지배구조 B(72)  Q7 자본배분 A(82)  Q8 집중도 C(59)  Q9 외부충격 B(68)
[종합]   B (73.1)  배수 1.00 → 채택   [결격] 통과
[주의]   Q5 잠재력 C — 신사업이 개발 단계뿐 / Q8 집중도 C — 최대 고객 22%
[★]      UNEXPLAINED_DOWN — 6개월 -34%, 영업이익 +12% → 원인 확인 필요
[미조사]  없음
```

## 8. 계산 예시

위 카드: 종합 = (80×15 + 92×15 + 70×10 + 65×10 + 55×10 + 72×15 + 82×10 + 59×10 + 68×5) ÷ 100 = 73.1 → **B**,
배수 1.00. Q6이 B라 상한 없음. Q3가 `missing`이면 분모에서 10을 빼고 나머지로 다시 평균한다.
Q1(0.8배)·Q8(최대 고객 22%)은 raw 수치의 앵커 보간으로 코드가 낸 점수다.

## 부록 A. 자기참조 차단 어휘 (근거·인용에서 검출되면 `weak`)

**주가·수급**: 급등, 급락, 신고가, 신저가, 낙폭과대, 반등, 순매수, 순매도, 공매도 잔고, 거래량 급증,
거래대금 상위 **심리**: 기대감, 관심 집중, 재평가 기대, 투자심리, 매력적 밸류에이션 **의견**: 목표주가, 매수 의견,
비중확대, 적정주가 **테마**: 관련주, 수혜주, 대장주, 편입 기대, 리밸런싱 수혜.
("수급"·"조정"·"테마"·"상승세"·"하락세"는 사업 서술에도 흔해 제외했다 — 예: 전력 수급, 연결 조정, 점유율 하락세.)
